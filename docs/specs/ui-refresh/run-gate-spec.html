Problem Statement

The player collects items but cannot see or manage them. Pickups vanish into a counter and nothing can be used on demand.

Solution

An inventory screen opened with Tab: a 6 × 4 grid of slots, stacks up to 99, and a small menu (Use, Drop, Details) on Enter. A full inventory leaves new pickups on the ground with a short message.

User Stories

  1. As the player, I want to open the inventory with Tab and close it with Tab or Esc, so that I can check my items without a menu.
  2. As the player, I want items shown in a grid with their stack count, so that I see what I carry at a glance.
  3. As the player, I want a menu on Enter with Use, Drop and Details, so that I act on one item at a time.
  4. As the player, I want a full inventory to leave new pickups on the ground and tell me, so that nothing is lost silently.

Implementation Decisions

  • One Inventory resource holds slots; the screen only reads it and sends actions.
  • Three 16 × 16 Assets: slot frame, selection cursor, count badge.
  • Keyboard only; controller navigation is out of scope.

Out of Scope

Crafting, item tooltips with lore, drag and drop, controller input.

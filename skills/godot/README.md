# Godot skills (placeholder)

Skills for the **game projects** Forgequor generates (GDScript/C#, scenes, GUT tests, game design, playtest).
Not loaded when working on Forgequor itself; the orchestrator installs `shared/` + `godot/` into generated Godot projects.

When installing into a game project, copy `skills/shared/trackers/codecks.md` to the project's `docs/agents/issue-tracker.md`
(fill in org, project and decks). The shared skills then publish specs and tickets to Codecks automatically.
